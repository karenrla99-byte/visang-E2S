# 마을 이미지 에셋

광장(마을 홈)은 지도 이미지 한 장 위에서 움직인다. 자세한 설명은 [`docs/DESIGN.md`](../../../docs/DESIGN.md) 5장, 이미지 요청문은 [`docs/ASSETS.md`](../../../docs/ASSETS.md).

| 파일 | 내용 |
|---|---|
| `plaza-map.jpg` | 광장 지도(16:9, 1376×768). 건물 핀·문 위치는 `public/village.js`의 `BUILDINGS`에 % 좌표로 있다. 지도를 바꾸면 이 좌표를 맞춰야 한다 |

그림 안에는 기능에 필요한 글자를 넣지 않는다(간판·안내는 코드가 얹는다).
