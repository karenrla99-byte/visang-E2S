# 캐릭터 이미지 (선택)

이 폴더에 아래 파일을 넣으면 **코드로 그린 도트 캐릭터 대신 이미지 캐릭터**가 광장·꾸미기 상점·상단 메뉴·공개 서재에 나온다. 코드는 고치지 않아도 된다(새로고침만).

| 파일 | 규격 |
|---|---|
| `character-walk.png` | **4열 × 4행 시트**, 투명 PNG. 행 순서(위→아래) = **아래(정면) · 왼쪽 · 오른쪽 · 위(뒷모습)**, 열 = 걷기 4프레임. 모든 칸 크기 동일(권장 112×152 → 시트 448×608), 머리 크기·발 높이 동일, 발이 칸 아래 가장자리에 닿게 |
| `item-<아이템id>.png` | 상점 아이템을 **캐릭터 위에 겹치는** 투명 시트. 위와 **똑같은 4×4 규격·같은 칸 크기**로, 아이템만 그린다(캐릭터 몸은 그리지 않음) |

아이템 id: `hat_scholar` `hat_beret` `hat_crown` · `outfit_cardigan` `outfit_cape` `outfit_pilot` · `acc_quill` `acc_bookrest` `acc_rose`

- 겹치는 순서: 몸 → 옷 → 모자 → 소품. 해당 파일이 없는 아이템은 겹치지 않는다(상점에서 사도 그림에는 안 나타남).
- 피부색 선택은 이미지 캐릭터에는 적용되지 않는다(코드 도트일 때만). 피부색을 쓰려면 몸 시트를 피부 레이어와 분리해 다시 설계해야 한다.
- 이미지 생성 요청문은 [`docs/ASSETS.md`](../../../docs/ASSETS.md) 2-1(캐릭터 시트)과 6장(아이템).
