# BookRest 디자인 가이드

> **콘셉트**: 노을빛 숲속 마을 도서관. 갈색(나무·흙·기와)과 초록(숲·풀)이 메인 컬러, 크림색 종이 바탕, 도트 한글 글꼴.
> **참고**: ① 사용자 제공 레퍼런스 이미지(노을 지는 숲 마을 — 돌 광장, 석조 도서관, 벤치·가로등, 개울과 돌다리) ② [`canedo-osung`](https://github.com/karenrla99-byte/canedo-osung)의 UI 규칙(4px 직각 테두리, 눌리는 버튼, 간판·키 안내, 포커스 링). **그림 파일은 가져오지 않고 규칙만 따른다.**
> 구현: `public/style.css`(토큰·컴포넌트), `public/village.js`(숲 마을). 이미지 요청문은 [`ASSETS.md`](./ASSETS.md).

## 2. 글꼴

- **Galmuri11**(도트 한글, OFL 1.1) — `public/fonts/`에 포함. 제목·메뉴·버튼·배지·간판.
- 긴 글(감상문 본문, 작품 설명, 입력 내용)은 읽기 쉬운 시스템 고딕(`--sans`). PRD 7장.
- 크기: 본문 16px, h1 1.6rem, h2 1.2rem, 보조 .88rem. `word-break: keep-all`.
- 로고는 흰 글자 + 짙은 갈색 8방향 외곽선 + 초록 아래 그림자.

## 3. 모양 규칙

- 테두리 4px, **직각**, 짙은 갈색. 둥근 모서리·블러 그림자 금지.
- 테두리는 `box-shadow: 0 0 0 4px` 로 그려 레이아웃을 밀지 않는다(요소에 `margin: 4px`).
- 눌림: 아래쪽 안쪽 그림자, 누르면 `translateY(4px)`.
- 떠 있는 상자(카드·간판·토스트): `0 6px 0 rgba(43,29,18,.3)` 단색 그림자.
- 도트 이미지는 `image-rendering: pixelated`(책 표지·업로드 사진 제외).
- 간격은 4의 배수.

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 주 버튼 `.btn` | 연초록 바탕 + 갈색 4px 테두리 + 안쪽 밝은 초록 링 + 아래 진한 초록 띠, 굵은 글자. 화면당 핵심 행동 하나 |
| 보조 `.btn.secondary` | 크림 바탕, 보통 굵기. 호버는 연한 초록 |
| 위험 `.btn.danger` | 크림 바탕 + 빨간 글자 |
| 칩 `.chip` | 흰 바탕 + 테두리. 선택(`aria-pressed`)은 초록 |
| 탭 `.tab` | 선택은 갈색 바탕 + 흰 글자, 아래 4px 갈색 선 |
| 카드 `.card` | 흰 바탕, 갈색 4px, 단색 그림자, 머리띠 `--band` |
| 입력창 | 흰 바탕, 갈색 4px, 높이 44px 이상 |
| 배지 `.badge` | 작은 글자 + 2px 테두리. 공개=초록, 숨김=빨강 |
| 토스트 | 크림 바탕, 갈색 4px, 아래 중앙 |
| 대화상자 | 갈색 8px 테두리 + 안쪽 흰 4px 링 |
| **포커스** | 모든 상호작용 요소: 노랑 4px + 짙은 갈색 4px 이중 링. 끄지 않는다 |
| 책 표지 | 갈색 4px 테두리 + 단색 그림자. 표지 없으면 제목 자동 표지 |
| 간판 | 크림 바탕 + 갈색 번호 상자(`01`) + 이름. 준비 중은 회색 |

## 5. 광장(마을 홈)과 탭 구성

AI Studio 프로토타입(`bookrest-*.zip`)의 구조를 그대로 따르고, 겉모습만 이 가이드의 픽셀 UI로 입힌다.

**상단 탭 (모든 로그인 화면 공통)**: `마을 홈` · `대도서관` · `내 서재` · `창작 전시관` · `꾸미기 상점` + 오른쪽에 **포인트 배지**(누르면 상점), 운영자는 `운영`, 내 캐릭터·닉네임(누르면 설정). 책 상세는 `대도서관`, 작품 상세는 `창작 전시관` 탭이 켜진 상태로 본다.

**광장**: 숲 마을 픽셀 지도(`public/assets/village/plaza-map.jpg`, 16:9) 위에서 내 캐릭터를 직접 움직인다.

| # | 건물 | 핀 위치 | 이동 |
|---|---|---|---|
| 01 | 대도서관 | 지도 왼쪽 큰 건물 | `#/library` |
| 02 | 창작 전시관 | 가운데 열린 전시장 | `#/gallery` |
| 03 | 내 서재 | 오른쪽 통나무집 | `#/shelf` |
| 04 | 꾸미기 상점 | 왼쪽 아래 천막 가게 | `#/shop` |
| 05 | 굿즈 공방 | 오른쪽 위 작은 집 | 준비 중(2차 오픈 안내) |

- 핀은 간판 스타일(번호 상자 + 이름 + 영문 부제). 문 앞에는 반짝이는 **입구 표시**가 있고, 가까이 가면 간판 위에 `[Enter] 들어가기` 말풍선과 지도 아래 `입장하기` 버튼이 뜬다.
- 캐릭터는 **피부색·모자·옷·소품(상점에서 산 것)이 그림에 반영되는 픽셀 아바타**(`public/avatar.js`). 머리 위에 닉네임 이름표.
- 건물 핀을 누르면 문 앞까지 걸어간 뒤 입장한다. `prefers-reduced-motion`이면 즉시 이동.

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 걷기(장면에 포커스가 있을 때) |
| 지도 클릭·탭 | 그 지점으로 걷기 |
| 건물 핀 클릭·탭, Tab+Enter | 문 앞까지 걸어가 입장 |
| 문 앞에서 Enter 또는 E | 입장 |

- **대체 수단(필수)**: 지도 아래 메뉴 목록과 상단 탭으로 같은 곳에 갈 수 있다.
- 지도 속 글자(예: 팻말)는 그림의 일부일 뿐 기능과 무관하다. 모든 안내는 HTML로 얹는다.

**포인트 규칙**: 가입 250P · 온보딩 완료 +200P(1회) · 책 담기 +50P(책당 1회) · 한 줄 평 +30P · 서평 +70P · 2차 창작 +120P. 상점 아이템은 모자 150~300P, 옷 200~280P, 소품 120~220P.

## 6. 입장 화면

노을 하늘 4단 띠 위에 외곽선 로고(`BookRest`), 크림 간판 문구, 로그인 버튼, 아래에 숲 실루엣 띠. 그 아래 `01 기록 / 02 창작 / 03 발견` 카드.

| 화면 | 구성 |
|---|---|
| 초기 설정 | 닉네임, 관심 분야 칩, 관심 책 고르기(서재에 담김, +200P), 건너뛰기 |
| 마을 홈 | 광장 지도 + 입장 안내 + 메뉴 목록 |
| 창작 전시관 | 분류 칩(전체·팬아트·굿즈 기획·외전·웹툰·기타) + 인기/최신 정렬 + 작품 카드(이미지, 원작, 작성자, 좋아요) |
| 꾸미기 상점 | 캐릭터 미리보기 + 피부색 + 모자·옷·소품 카드(구매/착용) |
| 대도서관 | 서고 사진 배너 + 검색 + 분야 칩(고전문학·인문학·철학·소설·사회/역사·과학/예술) + 표지 그리드 |

| 내 서재 | 읽기 상태 칩(전체·읽는 중·완독·읽고 싶은) + 선반 위 표지, `상태 · 기록 N · 공개 M` |
| 작성 | 종류·제목·본문·이미지·공개 설정(기본 비공개)·권리 확인 |
| 신고·운영 | 상태 칩 필터 + 신고 카드 |

## 8. 접근성

- 본문 대비 4.5:1 이상(짙은 갈색 `#2B1D12` / 크림 `#FBF4E2` ≈ 15:1).
- 포커스는 항상 보이게. 마을도 키보드만으로 모든 건물에 갈 수 있다(Tab → 카메라가 그 건물로 이동).
- 터치 대상 44px 이상(작은 버튼은 36px).
- 이미지 대체 텍스트: 책 표지 `「제목」 표지`, 업로드 이미지는 작성자 입력, 마을 장식은 `aria-hidden`.
- **마을 그림 안에 글자를 넣지 않는다.** 간판·안내는 HTML로 얹어 확대·읽어 주기가 되게 한다.

## 9. 하지 않는 것

- 둥근 모서리·블러 그림자·그라데이션(하늘 띠는 단색 4단), 순수 검정, 형광색, 네이비/파랑 UI(마을의 물·하늘 제외).
- 실제 책 표지를 도트로 바꾸기(PRD 1장: 표지는 실제 이미지).
- 참고 저장소 그림 파일 복사.
