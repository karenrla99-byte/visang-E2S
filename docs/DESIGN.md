# BookRest 디자인 가이드

> **콘셉트**: 노을빛 숲속 마을 도서관. 갈색(나무·흙·기와)과 초록(숲·풀)이 메인 컬러, 크림색 종이 바탕, 도트 한글 글꼴.
> **참고**: ① 사용자 제공 레퍼런스 이미지(노을 지는 숲 마을 — 돌 광장, 석조 도서관, 벤치·가로등, 개울과 돌다리) ② [`canedo-osung`](https://github.com/karenrla99-byte/canedo-osung)의 UI 규칙(4px 직각 테두리, 눌리는 버튼, 간판·키 안내, 포커스 링). **그림 파일은 가져오지 않고 규칙만 따른다.**
> 구현: `public/style.css`(토큰·컴포넌트), `public/village.js`(숲 마을). 이미지 요청문은 [`ASSETS.md`](./ASSETS.md).

## 2. 글꼴

- **Galmuri11**(도트 한글, OFL 1.1) — `public/fonts/`에 포함. 제목·메뉴·버튼·배지·간판.
- 긴 글(감상문 본문, 작품 설명, 입력 내용)은 읽기 쉬운 시스템 고딕(`--sans`). PRD 7장.
- 크기: 본문 16px, h1 1.6rem, h2 1.2rem, 보조 .88rem. `word-break: keep-all`.
- 로고는 흰 글자 + 짙은 갈색 8방향 외곽선 + 초록 아래 그림자.

## 3. 모양 규칙

- 테두리 4px, **직각**, 짙은 갈색. 둥근 모서리·블러 그림자 금지.
- 테두리는 `box-shadow: 0 0 0 4px` 로 그려 레이아웃을 밀지 않는다(요소에 `margin: 4px`).
- 눌림: 아래쪽 안쪽 그림자, 누르면 `translateY(4px)`.
- 떠 있는 상자(카드·간판·토스트): `0 6px 0 rgba(43,29,18,.3)` 단색 그림자.
- 도트 이미지는 `image-rendering: pixelated`(책 표지·업로드 사진 제외).
- 간격은 4의 배수.

## 5. 전체화면 마을 홈과 건물 탭 창

**첫 화면(로그인 후)은 전체화면 마을**이다. 지도가 화면을 가득 채우고(cover), 화면이 작으면 카메라가 캐릭터를 따라간다. 건물을 누르거나 들어가면 마을 위에 **탭 창**이 뜨고, 마을은 창 뒤에 그대로 남는다.

- **상단 HUD**: 마을 홈 · 대도서관 · 내 서재 · 창작 전시관 · 굿즈 펀딩 · 꾸미기(준비 중) + 포인트 + (운영자) 운영 + 내 캐릭터·닉네임(설정). 마을에서도 늘 보이는 대체 이동 수단이다.
- **건물 탭 창**: 갈색 제목줄에 탭(`대도서관` `내 서재` `창작 전시관` `굿즈 펀딩`)과 `× 닫기`. 닫기 방법은 ×버튼, `Esc`, 창 밖(어두운 배경) 클릭. 탭을 누르면 창 안에서 바로 전환된다. 설정·운영도 같은 창에 뜬다.
- 창이 열려 있는 동안에는 마을의 방향키 이동이 멈춘다.
- 건물 5곳: 01 대도서관 · 02 창작 전시관 · 03 내 서재 · 04 꾸미기 상점(준비 중) · 05 굿즈 펀딩. 핀은 간판 스타일(번호 상자+이름+영문 부제), 문 앞에는 입구 표시, 가까이 가면 `[Enter] 들어가기` 말풍선과 화면 아래 `들어가기` 버튼.
- **캐릭터**: 제공된 이미지 시트(`public/assets/avatar/character-walk.png`, 4×4)를 쓴다. 행 = 아래·왼쪽·오른쪽·위, 열 = 걷기 4프레임. 꾸미기는 나중에 구현(상점은 "준비 중").

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 걷기(창이 닫혀 있고 마을에 포커스가 있을 때) |
| 지도 클릭·탭 | 그 지점으로 걷기 |
| 건물 핀 클릭·탭, Tab+Enter | 문 앞까지 걸어가 창 열기 |
| 문 앞에서 Enter 또는 E | 창 열기 |
| `Esc` | 열린 창 닫기 |

**포인트 규칙**: 가입 250P · 온보딩 완료 +200P(1회) · 책 담기 +50P(책당 1회) · 한 줄 평 +30P · 서평 +70P · 2차 창작 +120P.

### 굿즈 펀딩 (관심 표시)
2차 창작 중 **굿즈 기획**은 펀딩 상태가 한눈에 보인다. **결제는 없다**(PRD 3장: 좋아요도, 관심 표시도 금전적 후원이나 펀딩 약속이 아니다).
- 굿즈 카드·작품 상세·대도서관 목록 어디서든 **진행률 막대**(`관심 N / 목표 M명 · P%`)가 보이고, 목표 달성 시 금색 `★ 목표 달성`.
- `♡ 관심 표시하기`는 좋아요와 **별개 버튼**이다. 본인 기획·비공개·숨김 작품에는 불가. 안내문은 항상 함께 둔다: "아직 결제는 없어요… 목표에 모이면 제작사 연결을 검토해요(준비 중)".
- 작성자는 굿즈 작성란에서 **목표 관심 수(10~1000)**와 **제작 구상(가격·수량·소재, 200자)**을 적는다.
- 건물 05 `굿즈 펀딩` 창: 진행 방식 3단계(기획 올리기 → 관심 모으기 → 제작 검토) 안내 + 진행률순/관심 많은 순/최신순 목록.

### 대도서관 책 상세의 종류별 탭
2차 창작을 한 탭으로 묶지 않고 **9개 종류를 모두 따로** 보여 준다(건수 포함, 0건도 표시): 한 줄 평 · 서평·독후감 · 팬아트 · 굿즈 기획 · 코스프레 · 외전·평행세계 글 · 웹소설 · 웹툰 · 기타. 2차 창작 종류에서만 좋아요순 정렬을 쓴다. 상단 인기 TOP 3은 책별 전체 공개 2차 창작물 기준.

### 작성란 템플릿 (종류별)
| 템플릿 | 종류 | 칸 |
|---|---|---|
| 한 줄 | 한 줄 평 | 한 줄 평(300자) |
| 에세이 | 서평·독후감 | 제목 · 본문 |
| **이미지형** | 팬아트 · 코스프레 · 웹툰 | 제목 · **이미지 업로드(필수, 팬아트·코스프레 4장, 웹툰 컷 10장)** · 작품 소개(선택) |
| **글형** | 외전·평행세계 글 · 웹소설 | 제목 · **소개칸(필수, 500자)** · **내용칸(필수, 본문)** — 소개와 내용이 분리, 이미지 없음 |
| 굿즈 | 굿즈 기획 | 제목 · 기획 소개(필수) · 이미지(선택) · 목표 관심 수 · 제작 구상 |
| 자유 | 기타 | 제목 · 소개 · 내용 · 이미지 중 하나 이상 |

공개로 저장하려면 저작권·개인정보·초상 확인에 동의해야 한다. 코스프레 안내에는 타인 얼굴 동의 문구를 둔다.

## 8. 접근성

- 본문 대비 4.5:1 이상(짙은 갈색 `#2B1D12` / 크림 `#FBF4E2` ≈ 15:1).
- 포커스는 항상 보이게. 마을도 키보드만으로 모든 건물에 갈 수 있다(Tab → 카메라가 그 건물로 이동).
- 터치 대상 44px 이상(작은 버튼은 36px).
- 이미지 대체 텍스트: 책 표지 `「제목」 표지`, 업로드 이미지는 작성자 입력, 마을 장식은 `aria-hidden`.
- **마을 그림 안에 글자를 넣지 않는다.** 간판·안내는 HTML로 얹어 확대·읽어 주기가 되게 한다.

## 9. 하지 않는 것

- 둥근 모서리·블러 그림자·그라데이션(하늘 띠는 단색 4단), 순수 검정, 형광색, 네이비/파랑 UI(마을의 물·하늘 제외).
- 실제 책 표지를 도트로 바꾸기(PRD 1장: 표지는 실제 이미지).
- 참고 저장소 그림 파일 복사.
