# BookRest 이미지 에셋 목록과 요청문

> **갱신**: 광장은 프로토타입의 숲 마을 지도 이미지(`plaza-map.jpg`)를 쓰도록 바뀌었다. 그래서 아래 **2장(걷는 월드용 건물·배경·나무·소품) 중 `plaza-map`을 대체하는 항목은 지금 코드가 읽지 않는다.** 지금 필요한 새 에셋은 맨 아래 **6장**을 본다. 2장은 월드 방식으로 되돌릴 때를 위한 참고로 둔다.
> 쓰는 법: ① 아래 **「공통 스타일 블록」**과 **레퍼런스 이미지**(노을 숲 마을)를 이미지 생성 도구에 먼저 첨부·붙여 넣고 ② 요소별 요청문을 **한 번에 하나씩** 보낸다 ③ 받은 PNG를 표의 **파일명 그대로** `public/assets/village/`에 넣는다. 파일이 없으면 코드로 그린 기본 도트가 나오므로 **하나씩만 넣어도 된다.**
> 디자인 기준은 [`DESIGN.md`](./DESIGN.md). 규격은 `public/assets/village/README.md`와 같다.
> 상태: 🟢 코드에 연결됨(파일만 넣으면 교체) · ⚪ 아직 코드 연결 없음(필요해지면 요청)

## 0. 공통 스타일 블록 (모든 요청문 앞에 붙인다)

```
[BookRest 공통 스타일]
첨부한 레퍼런스 이미지(노을빛 숲속 마을)의 그림체와 분위기를 따라 줘.
- 2D 픽셀 아트. 픽셀 가장자리는 선명하게(번지는 부드러운 3D·수채화·사실화 금지). 같은 세트의 그림은 픽셀 한 칸의 크기와 선 굵기가 같아야 해.
- 시점: 살짝 위에서 내려다본 3/4 시점(건물은 앞면과 지붕이 보이고, 땅은 비스듬히 보이는 시점).
- 따뜻한 노을빛. 빛은 왼쪽 위에서, 그림자는 오른쪽 아래로 부드러운 한 단계만.
- 팔레트: 테라코타 기와 #B2503A, 크림색 돌벽 #E3D3B0, 이끼 초록 #4A7A30 · #628F38 · #7FAE49, 풀 #7C9F48, 나무 갈색 #6B4526 · #9A6A3C, 창문 불빛 #FFD98A, 노을 복숭아색 #F6CFA9, 돌길 #D9C9A4. 순수 검정 금지, 어두운 부분은 짙은 갈색(#2B1D12)으로.
- 굵은 검은 외곽선은 쓰지 않는다. 필요하면 물체보다 한 단계 어두운 같은 색의 얇은 선만.
- 큰 색 덩어리와 제한된 명암. 잔털·옷 주름·복잡한 질감은 줄인다.
- 배경은 투명 PNG(지정한 경우만 제외). 글자·번호·격자선·워터마크는 그리지 않는다.
- 여러 칸 이미지는 칸마다 그림 하나, 칸 사이는 넉넉히 띄우고, 같은 축척으로.
- 실존 게임·애니메이션의 캐릭터나 장식은 가져오지 않는다.
```

각 행의 4칸은 걷기 한 바퀴: 1칸 오른발 앞, 2칸 두 발 모음, 3칸 왼발 앞, 4칸 두 발 모음.
모든 칸에서 머리 크기·몸 크기·발바닥 높이를 똑같이 하고, 발이 칸의 아래쪽 가장자리에 닿게, 가로는 가운데에 맞춰 줘.

## 4. 받은 그림 검수 체크리스트

- [ ] 파일명·크기가 표와 같다(비율이 많이 다르면 화면에서 찌그러지거나 크기가 달라진다)
- [ ] 투명이 필요한 그림에 **흰 배경이 남아 있지 않다**
- [ ] 발·밑바닥이 이미지 아래 가장자리에 닿는다(안 닿으면 바닥에서 떠 보임)
- [ ] 격자선·번호·글자·워터마크가 없다
- [ ] 같은 세트의 픽셀 크기와 선 굵기가 같다(건물만 크고 캐릭터만 거친 식으로 어긋나지 않게)
- [ ] 캐릭터 시트: 4행 방향 순서 `아래·왼쪽·오른쪽·위`, 프레임마다 머리 크기·발 높이 동일
- [ ] 마을에서 건물·길·캐릭터가 배경보다 먼저 읽힌다(배경은 대비 약하게)
- [ ] 실존 작품의 캐릭터·장식을 닮지 않았다

## 5. 넣은 뒤 확인

`npm start` → 로그인 → 마을 홈에서 눈으로 확인한다. 이미지가 일부만 있어도 나머지는 기본 도트로 채워진다. 건물 높이·위치는 `public/village.js`의 `PLACES`(x, y, w, h), 캐릭터 높이는 `CH_H`로 조정한다.
